DataTable Basic

DataTable displays data in tabular format. Powered by JettraEE with Virtual Threads.

Products Live DataTable Bean: #{dtBasicView.products}
Source Code (PrimeFaces Showcase Specification) 
<div class="card">
    <h:form id="form">
        <p:dataTable var="product" value="\#{dtBasicView.products}">
            <p:column headerText="Code">
                <h:outputText value="\#{product.code}" />
            </p:column>

            <p:column headerText="Name">
                <h:outputText value="\#{product.name}" />
            </p:column>

            <p:column headerText="Category">
                <h:outputText value="\#{product.category}" />
            </p:column>

            <p:column headerText="Quantity">
                <h:outputText value="\#{product.quantity}" />
            </p:column>

            <p:column headerText="Price">
                <h:outputText value="$\#{product.price}" />
            </p:column>

            <p:column headerText="Rating">
                <p:rating value="\#{product.rating}" readonly="true" />
            </p:column>

            <p:column headerText="Status">
                <p:tag severity="\#{product.inventoryStatus.severity}" value="\#{product.inventoryStatus.text}" rounded="true" />
            </p:column>
        </p:dataTable>
    </h:form>
</div>
