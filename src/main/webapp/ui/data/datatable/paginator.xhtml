DataTable Paginator

DataTable has built-in pagination support with configurable rows per page and navigation controls.

Products with Paginator (5 rows per page) Bean: #{dtPaginatorView.products}
Source Code 
<p:dataTable var="product" value="\#{dtPaginatorView.products}" rows="5" paginator="true">
    <p:column headerText="Code">
        <h:outputText value="\#{product.code}" />
    </p:column>
    <p:column headerText="Name">
        <h:outputText value="\#{product.name}" />
    </p:column>
    <p:column headerText="Category">
        <h:outputText value="\#{product.category}" />
    </p:column>
    <p:column headerText="Quantity">
        <h:outputText value="\#{product.quantity}" />
    </p:column>
</p:dataTable>
